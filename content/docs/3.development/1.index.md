## Basics

Using [Nuxt](https://nuxt.com/docs/4.x/getting-started/introduction) Framework with [Bun](https://bun.com/).

**Free and Open Source** with minimal data collection. Human-made content and code.

## Code Practices

- Balance between a long list and sideways scrolling. 
- Support for different input methods using a browser.
- Smooth animations with [Tailwind](https://tailwindcss.com/docs) CSS or [Motion](https://motion.unovue.com/getting-started/introduction).
- Validation and queries using [Zod 4](https://zod.dev/v4/changelog)
- **Sqlite** database and **yml** and **md** files for content
- Minimal Cookies, no Ads.
